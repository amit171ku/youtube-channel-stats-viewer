## 📖 Overview

**YouTube Channel Stats Viewer** is a modern **website** (web application) that lets you instantly analyze and visualize any YouTube channel’s public statistics.  
No installation required—just open the website in your browser and get started!

---

## 🌟 Features

- **Channel Overview:** Instantly see total subscribers, total views, and channel description.
- **Video Analytics:** Browse all videos with individual stats (views, likes, publish dates).
- **One-Click Insights:** Paste any YouTube channel link to get comprehensive analytics.
- **Channel Comparison:** Analyze and compare multiple channels side by side.
- **Real-Time Data:** Always up-to-date, powered by YouTube’s public data.
- **Privacy-Friendly:** No login or personal data required.
- **Responsive Design:** Works perfectly on desktop and mobile browsers.

## 🚀 How to Use

1. **Open the website:**  
   [youtube-channel-stats-viewer.vercel.app](https://youtube-channel-stats-viewer.vercel.app/)

2. **Analyze a Channel:**  
   - Copy the URL of any public YouTube channel.
   - Paste it into the input field.
   - Click **Get Stats**.
   - Instantly view analytics, video breakdowns, and more.
